# joaco2v.github.io

Sitio raíz de GitHub Pages de [joaco2v](https://github.com/joaco2v).

- Redirige a la app [Completómetro](https://joaco2v.github.io/completometro/) ([código](https://github.com/joaco2v/completometro)).
- Aloja el archivo de verificación de Google Search Console, necesario para verificar el dominio
  `joaco2v.github.io` en la pantalla de consentimiento de Google (respaldo en Google Drive del Completómetro).
